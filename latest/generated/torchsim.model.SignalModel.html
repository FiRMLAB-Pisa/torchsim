SignalModel#

class torchsim.model.SignalModel(**values)[source]#

Bases: ABC

One signal model: declared properties, and a signal.

Subclasses set properties and implement evaluate().

The constructor takes the keywords simulate() takes, and fixes them; a call overrides. bind() fixes more on a copy, so what a caller is left to give per call is whatever is actually varying.

properties#

What the model exposes, as names. A mapping is read for its keys, so a subclass that also needs to say where each property goes – as SpinPhysics does, naming the tissue field each fills – declares both at once.

Type:

mapping or sequence of str

bound#

The arguments fixed on this model, under the names simulate() takes them by. A call may name any of them again, and the call wins.

Type:

mapping

abstractmethod evaluate(properties, **sequence)[source]#

Return the signal these properties and this sequence record.

properties holds the declared values the caller passed, under the names properties gives them, and holds nothing for those the caller left out. Public units are the caller’s – milliseconds and degrees – and converting them belongs here, with the sequence.

property exposes#

The property names this model declares, in its own order.

property accepts#

what is declared, and the rest.

A model declares the vocabulary its protocol is written in, and a voxel has more fields than any one model names. Both are accepted, so asking for off-resonance or a second pool is giving one a value rather than rebuilding the model around it.

Type:

Every property name a call may use

This model with more arguments fixed on it, or some of them changed.

simulate(**values)[source]#

Return the recorded signal.

Property and sequence arguments are given together and told apart by properties, and join whatever bound already holds. A cost built on this and differentiated with torch.Tensor.backward() reaches the engine’s adjoint, which is the mode that suits a sequence parameter.

jacobian(diff, **values)[source]#

Return the signal and its derivative with respect to diff.

Forward mode, one directional derivative per differentiated property. Voxels are independent, so each pass yields every voxel’s derivative at once and the cost is one pass per property rather than per voxel.

Parameters:

  • diff (str or sequence of str) – One property name, or several. A single name collapses the parameter axis; a sequence keeps it, stacked before the samples.

  • values (float or array-like, optional) – The property and sequence arguments, as for simulate().

Returns:

The signal, and its Jacobian.

Return type:

tuple

Raises:

ValueError – If diff names something the model does not expose, or something that carries no derivative.
